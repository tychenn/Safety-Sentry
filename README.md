# Safety Sentry project page

Website: https://tychenn.github.io/Safety-Sentry/

This repository hosts the project page for **Safety Sentry: Context-Aware Human Intervention via EXECUTE–ASK–REFUSE Routing** by Tianyu Chen, Chujia Hu, and Wenjie Wang.

- Paper: https://arxiv.org/abs/2607.13594
- Official research code and data: https://github.com/safesentry/SAFETY-SENTRY
- Hugging Face Papers: https://huggingface.co/papers/2607.13594

The page uses plain HTML, CSS, and JavaScript. Edit `index.html` for content, `styles.css` for appearance, and `script.js` for citation copying and section navigation. GitHub Pages publishes from the root of the `main` branch.

Figures and reported results are reproduced from Safety Sentry. The page layout is inspired by the [Kairos project page](https://mldi.group/Kairos/).
